# YolanLive v1.1.7 发布检查

2026-11-04。发布用户确认的播放器文字对齐修正，并更新 GitHub 项目介绍。软件、关于页及安装器统一为 1.1.7；版本沿用既有发布序列。

## 更新内容

- 画质、线路标签与选中值统一使用共享正文 14 号字，显式设置原生下拉框内容垂直居中。修正前标签基线比选中值高约 0.968 DIP，修正后相同字体、主题与窗口宽度下基线一致。
- 保留两组选项等宽伸缩、现有箭头空间、主题色和小窗精简栏，不调整播放参数、平台接口、窗口模式或资料格式。
- README 图标从 80×80 放大至 160×160 并居中，标题同步居中；首页、分类和播放器换成 v1.1.7 隔离访客环境实际截图，使用独立版本路径避免旧图缓存。
- 新增显式 `--smoke-test --readme-screenshots` 文档截图入口，只读取隔离目录、访客平台数据并截取本应用客户区；不读取日常会话，不对画面进行拼接或合成。启动正常软件不会执行此入口。

## 本地检查

所有检查使用本机工具、D 盘缓存和隔离访客／测试安装身份；未覆盖日常安装。原始记录位于 `v1.1.7/`。

- `visual.txt`：26 项原生布局检查通过。新增实际播放器标签与选中值的文字基线、选中内容与箭头空间检查；浅深主题、960×540 与 1280×720 下两处基线差为 0。沿用既有分类、顶栏、侧栏、搜索、卡片与设置布局检查。
- `browsing.txt`：8 项浏览交互检查通过，覆盖图片卡片、筛选、大类换行、固定入口、缓存返回及加载反馈。
- `update-offline.txt`：9 组受控更新检查通过，包括大小与 SHA-256、取消、续传、损坏拒绝、换源、超时及手动启动安装器。
- `legacy-offline.txt`：不可变 v1.0.6 更新器接受直接升级至 1.1.7 的兼容元数据，保留对其他仓库地址的拒绝。
- `icons.txt`：程序及安装器嵌入图标与 D4 蓝青风翼源 ICO 匹配。本轮仅放大 README 图标，没有重新设计应用图标或修改快捷方式刷新逻辑；不宣称已解决所有 Explorer 图标缓存问题。
- `versions.json`：软件、主程序集及安装器版本一致，程序和安装器仍未签名。
- `screenshots.txt`：真实虎牙访客首页、游戏目录与真实播放截图成功；首个播放候选未在 30 秒内成功，改用下一个候选。截图不是四平台全线路验证，不能据此宣称所有虎牙线路均可用。
- `package.json`：便携 ZIP 与正式运行目录逐文件 SHA-256 校验，检查运行依赖、字体与许可，排除账号、数据库、日志及测试目录。
- `installer.txt`：取消桌面入口、默认当前用户安装、版本及图标、覆盖安装替换旧图标路径、恢复程序文件并保留假资料通过；安装后完整冒烟 **118/118**，安装检查退出 0。
- `smoke-test.txt`：保留完整安装后冒烟结果。本次未复现历史全屏视口尺寸失败，但没有修改该问题相关逻辑，不能据此宣称间歇问题已经修复。
- `installer-cleanup.txt`：测试卸载后独立检查测试注册表、桌面及开始菜单入口、测试程序与假资料均已移除。

## 历史限制

既有窗口内全屏视口预期 1280×719、实际 1280×779 的间歇失败，虎牙部分线路 HTTP 403，以及软件内无代理完整更新下载超时记录继续保留。本轮没有修改对应逻辑，不宣称修复。

不重复四平台全线路、登录后播放、长期性能、150%／200% 实机缩放及系统高对比度切换验收。实际文字检查环境 RasterizationScale 为 1。
