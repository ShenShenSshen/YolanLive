# YolanLive v1.1.6 发布检查

2026-11-03。发布用户确认的分类两层导航与搜索布局，保留更纱 UI SC、圆体大标题、浅深主题及 D4 蓝青风翼图标。软件、关于页版本来源与安装器统一为 1.1.6；没有改动平台接口、播放参数、窗口模式或用户数据格式。

## 更新内容

- 分类平台项使用 88×44 的统一区域和细下划线，取消额外左边距；根据实际平台项宽度计算顶栏预算，刷新与搜索按钮避开原生窗口按钮。
- 大类按名称宽度排列、空间不足换行，保留完整名称、淡色圆角选中反馈、原生单选与键盘焦点。小型导航面板不影响游戏卡片虚拟化，没有新增依赖或轮询。
- 分类页全平台搜索收为顶部图标，当前平台找游戏留在大类右侧；内容区不足 640 时收为按钮，复用输入框、保留筛选词并显示标记。退出页面关闭弹层、退订文本属性回调。
- 沿用既有字号、行高、轻量动画和颜色，首页与播放器的布局保持现状。完整设计说明见 [分类导航预览](category-navigation-preview.md)。

- `versions.json`：exe、主程序集和安装器文件版本为 1.1.6.0，安装器产品版本 1.1.6；程序与安装器均未签名。
