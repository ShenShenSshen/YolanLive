# 整体可用性调整 · 本地预览

2026-11-02。按已确认的七项审查建议及小问题实施，保留已通过的浅色影音配色、圆体导航、微软雅黑 UI 正文与关注状态分组。版本保持 1.1.3；本轮未提交、打包或发布 GitHub，未覆盖日常安装。

## 调整范围

1. **浏览窗口与播放窗口分开管理**：浏览时可原生调整大小、最大化，交互缩放最小为 640×360 逻辑单位；播放仍按现有比例与预设约束。主窗口进入播放前保留浏览边界与最大化状态，返回后恢复。位置设置新增可选的宽、高与最大化字段，兼容缺少这些字段的旧设置；SQLite 与关注／历史导入导出格式不变。
2. **搜索含义明确**：首页、分类、关注、历史和设置的顶栏输入明确为“全平台搜索或粘贴链接”。关注、历史另外提供“筛选关注／筛选历史”，仅过滤已保存的主播、平台或房间号，不发起网络搜索，不更改保存记录。
3. **刷新稳定**：按记录 ID 复用对象，差量增删移动集合，正常刷新不再 Clear／Reset 整组。原生列表在更新前记录可见锚点和键盘焦点，更新后一次性恢复，初次加载保持列表顶部；未新增轮询计时器。
4. **窄窗口入口稳定**：全局搜索不足宽度时收为原顶栏位置的搜索按钮，展开原生输入浮层，不再搬回侧栏。平台在必要时仍可换行，管理等次要操作沿用更多菜单；保留原生标题栏的交互与拖动区域预算。
5. **历史按任务组织**：改为原生单列记录列表，按今天／昨天／更早分组，显示主播、平台与简短时间；使用原有保存数据，不额外拉取房间详情或增加数据库字段。右键移除、清空、打开记录继续保留。
6. **播放器名称明确**：入口使用“窗口大小”“窗口模式”，无边框模式统一称为“无边框播放”；普通窗口、小窗和全屏等原有行为不变。菜单按钮相应加宽，工具栏预算改为读取实际按钮宽度，画质／线路仍等宽伸缩。
7. **更新失败可恢复**：失败后提供重试下载、浏览器下载／前往发布页、复制下载／发布页链接。已取得并验证元数据时链接指向对应公开安装包的加速 URL；元数据不可用时仅提供本项目正式发布页，不猜版本或安装器地址。文件大小、SHA-256 和手动启动规则继续保留。
8. **小问题**：删除关于页的字体实施说明，统一四个平台的“登录／退出登录”文案，保留版本、项目主页和运行日志入口。设置与播放器的窗口大小说明统一。

## 验证

使用本机工具与 D 盘缓存编译。所有运行检查均采用 D 盘隔离访客目录，不读取日常账号，不执行公开安装器，不修改用户剪贴板或自动打开浏览器。

- `usability/all.txt`：**7 组专项检查通过**，包含原有关注分组检查、本地筛选与数据保留、稳定对象引用和无 Reset 更新、历史日期与平台标识、浏览／播放／返回的窗口恢复、宽窄窗口搜索与筛选、原生关注重分组后的可见锚点和键盘焦点、更新失败恢复链接。
- `usability/visual.txt`：**25 项既有原生布局检查通过**，覆盖浅色／深色、侧栏展开与收起、搜索及刷新不遮挡、完整平台标签、卡片比例、设置响应式行与失败重试。旧的“窄窗口搜索回侧栏”断言改为检查原顶栏搜索按钮，保留遮挡、间距及键盘焦点要求。
- `usability/smoke.txt`：**118/118 项既有冒烟检查通过**，包括播放、窗口模式、比例、随机浏览、导入与保存、登录会话保护及更新文件校验。固定预设检查显式在播放上下文执行；设置改变后另行断言浏览窗口仍允许缩放和最大化。
- `usability/red-filter.txt` 与 `navigation-fixture-failure.txt`：保留初始原生用例失败。定位为测试直接设置 Frame.Content，未执行历史页 OnNavigatedTo，导致加载前记录即为空；改为 Frame.Navigate 的真实用户导航流程后通过，未放宽恢复数量断言或增加重复生产加载。

本轮既有窗口内全屏尺寸断言通过，但未定位其历史间歇失败根因；此前记录继续保留。未重新实测四平台全部真实线路、150%／200% 物理缩放、系统高对比度切换或长期性能。高对比度资源继续沿用系统颜色。

更新部分只补充失败恢复操作，**没有将 v1.1.3 发布后无代理完整下载超时标为已修复或重新验证通过**。自动下载仍依赖已接入的公共加速源和 GitHub API。

## 运行与复现

完整预览目录：`artifacts/YolanLive-usability-preview`。运行其中 `YolanLive.exe`，保留所有运行依赖文件。

```powershell
& .\with-build-cache.ps1 {
    dotnet publish .\YolanLive.WinUI\YolanLive.csproj -c Release -p:Platform=x64 `
        -o .\artifacts\YolanLive-usability-preview --nologo
}
& .\tests\UsabilityCheck.ps1
& .\tests\UsabilityCheck.ps1 -Mode visual
& .\tests\UsabilityCheck.ps1 -Mode smoke
```

使用手感、清晰度及实际多屏拖动由用户继续体验；本轮未做基于旧截图的视觉结论。
