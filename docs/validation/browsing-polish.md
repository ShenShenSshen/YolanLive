# 浏览体验收尾，本地预览

日期：2026-11-02。版本保持 1.1.3，本轮没有安装包、GitHub 提交或发布。

预览入口：`artifacts/YolanLive-browsing-preview/YolanLive.exe`。运行和复制时保留整个预览目录及依赖。

## 六项调整

1. 直播封面目标单元宽度由 320 改为 280，按最接近的列数分配宽度，避免在旧断点附近只剩一张过大的封面。保持物理像素向下取整、封面 16:9 和文字原生字号；分类、关注卡片的列数算法不变。
2. 分类新增“找游戏：当前平台”，在已经加载的当前平台目录中跨大类按名称筛选，不发起额外请求，不改变分类 ID 或跳转平台。清空后恢复原大类，刷新保留筛选，切换平台清空；没有匹配结果后离开返回不会误触发重新加载。宽内容区与大类同行，不足 760 DIP 时移到下一行。
3. 游戏卡片的固定按钮在悬停或键盘聚焦时出现，已固定状态保持可见；支持直接固定及取消。沿用原右键菜单、保存格式、每平台最多 6 个的限制和首页入口。卡片卸载时退订交互事件，回收、返回后重新同步状态。
4. 等待提示依据实际执行顺序显示获取直播间、读取画质、获取播放线路；地址交给现有播放器后显示连接、打开或缓冲。没有虚构百分比。取消和过期响应不留下请求提示，也不会启动旧播放。取消、超时、解码和重试策略不变，没有增加请求或第二个播放器。
5. 每个页面实例首次加载时保留轻淡入，缓存页面返回时直接恢复；平台、大类的局部反馈及 Windows 关闭动画的行为保留。没有新增计时器。
6. 游戏图片保持 4:3 展示区域、Uniform 完整显示和统一 12 DIP 安全留白。图片区域使用轻底色，深色主题下提供浅中性色背板，让透明、深色图标有边界；缺图提示采用相应高对比文字，高对比度模式使用系统颜色。没有裁切原图、处理图片内部自带空白，或新增磁盘图片缓存。

保留当前字体、配色、磨砂、前轮关注分组和其他已通过的本地调整。

## 边界

本轮验证在实际 100% 缩放下运行，浅深主题及窄内容区已检查；150%/200% 物理显示和操作系统高对比度模式的实际观感仍需人工体验。原生界面布局、图片像素及可控请求检查不等于四平台真实直播全线路实测。等待阶段更明确不代表网络或首帧速度变快；历史全屏视口和更新下载网络限制也不因此宣称已解决。
