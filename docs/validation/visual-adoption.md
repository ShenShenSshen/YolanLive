# 圆体大标题、更纱 UI SC 与 D4 图标整合

2026-11-02。用户确认 D4 蓝青双色风翼，并认可原尺寸对照中的“圆体大标题＋更纱 UI SC”。本轮将选择应用到实际页面，保留版本 1.1.4，仅交付本地完整预览，不生成安装包、不发布 GitHub、不覆盖日常安装。

运行入口：`artifacts/YolanLive-visual-preview/YolanLive.exe`，需要保留整个目录。

## 字体

- `HeadingFontFamily`：资源圆体 Regular，用于 22 号页面大标题和 18 号字标。
- `ContentControlThemeFontFamily`：更纱黑体 UI SC Regular。
- 导航、正文、按钮、说明、数字与直播间标题栏共用更纱字体；导航与数字资源指向同一共享资源，移除输入样式中单独指定微软雅黑 UI 的覆盖。
- 正文及导航保留 14 号、说明保留 13 号、分组标题保留 16 号；原行高、间距、颜色、布局和窗口模式不变，不通过缩放控件放大文字。
- 更纱使用官方 v1.0.43 带 TrueType 微调的 TTF Regular，随包提供原 OFL 授权，不安装系统字体、不增加运行库。
- 为保留先前字体对照，旧字体文件暂保留；日常界面不再混用旧字标、正文和数字字体。对照窗口仍能展示旧、新组合。

此前预览专用的外部字体资源开关已移除：选定的字体现在随标准 Assets 打包，源码构建不再依赖 artifacts 下的字体原稿。

## 图标

- 形状：用户选择的两片风翼，不变更轮廓。
- 背景 `#EFF8FC`，上翼 `#5F91C9`，下翼 `#60B8BC`。
- 同步 `Assets/YolanLive.svg`、512 像素 PNG、多尺寸 ICO；ICO 包含 16、20、24、32、40、48、64、96、128、256 像素。
- 原有 exe、运行窗口、程序图片和未来安装器沿用同一资产路径，因此共同使用新图标；本轮没有生成或安装新安装器，已安装的旧软件及快捷方式未被替换。
- 图标检查继续逐像素比较 exe 内嵌图标与源 ICO，只更新旧 D1 的描述，不删除比较。

- `visual-adoption/visual.txt`：25 项原生布局检查通过，覆盖浅深主题、侧栏、搜索与窗口按钮、大类完整文字、图片比例、设置行和重试状态。
- `visual-adoption/icons.txt`：exe 内嵌图标与源 D4 ICO 逐像素匹配。源 SVG、PNG、ICO 的 SHA-256 与运行目录分别一致。
