# 游岚 YolanLive v1.0.10 发布检查

日期：2026-10-20。以 v1.0.9 为基线，修复覆盖升级的图标缓存路径，并同步旧 PlayWin 更新源。未修改平台请求、播放器参数、窗口模式或用户数据格式。

## 本地检查

- 使用本机 .NET SDK、Inno Setup 和 D 盘缓存构建，程序、程序集、关于页来源和安装器统一为 1.0.10。[程序集版本](v1.0.10/versions.json)、[安装器版本](v1.0.10/installer-version.json)。
- [隔离安装检查](v1.0.10/installer.txt)通过：默认桌面快捷方式、允许取消创建、版本图标文件及内容一致、旧快捷方式图标路径覆盖替换、覆盖安装保留资料、已安装程序 113 项冒烟、卸载清空测试资料及浏览器缓存。使用独立测试 AppId，不改动日常安装和账号。
- [图标检查](v1.0.10/icons.txt)通过：正式 exe 与安装器的内嵌 D1 图标像素一致。安装完成后调用系统 Shell 缓存刷新通知；此检查不等同于所有机器的桌面或任务栏视觉验收。指向其他旧程序路径的固定入口可能需要重新固定。
- [便携包检查](v1.0.10/package.json)通过：582 个文件逐一 SHA-256 一致，必需运行文件齐全，无账号、数据库、日志或测试目录。
- [旧更新器离线检查](v1.0.10/legacy-offline.txt)使用 v1.0.6 标签的原始更新器代码，确认它可直接识别 v1.0.10 的旧文件名元数据，且仍拒绝非旧仓库地址。没有放宽下载地址或 SHA-256 校验。

## 公开更新入口验收

正式发布后运行 `sync-legacy-update.ps1` 和 `-CheckOnly`，将当前正式包逐字节同步至旧 PlayWin 仓库，以旧文件名供旧客户端直接更新。发布前核对安装器大小和 SHA-256，草稿核对通过后公开。现场结果另存本目录的 `v1.0.10/legacy-live.txt` 和 `v1.0.10/update-live.txt`。

## 范围与限制

本次不重复四平台实际播放、长期性能及高 DPI 实机验收。沿用 [v1.0.9](release-1.0.9.md) 的 B站访客选房失败、虎牙所选线路解码失败记录，不宣称全部平台、所有图标缓存环境通过。软件和安装包仍未签名。

覆盖升级保留设置、关注、历史与登录资料；安装版卸载清空应用数据。旧 PlayWin 兼容入口与主仓库使用同一安装器二进制，仅下载文件名不同。
