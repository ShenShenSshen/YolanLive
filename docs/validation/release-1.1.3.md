# YolanLive v1.1.3 发布检查

2026-11-01。基于 v1.1.2 发布已完成的更新下载加速；程序、关于页版本来源、安装器统一为 1.1.3。保留现有界面、平台接口、播放参数、安装身份及用户资料格式。

## 本次改动

- 安装包依次尝试 gh-proxy.org、ghfast.top、GitHub 原站，失败换源并显示当前源。
- 取消或网络中断保留未完成文件，重试及跨源使用 Range 续传；服务器忽略 Range 时重新写入，范围异常不拼接。
- 响应头 15 秒、读取连续 20 秒无进展时取消底层请求；全程最多 15 分钟，用户取消后不再切换。
- 版本、文件名、大小及 SHA-256 仍直接读取 GitHub 正式发布，校验通过后才改为安装器名称，执行前再次校验。公共源不接收账号 Cookie 或令牌。
- 未新增依赖；未修改播放参数、用户数据格式或普通页面布局。

设计选择、红绿记录和预览实网验证见 [下载加速报告](update-acceleration.md)。预览已在禁用显式代理的本机环境经加速源完整下载 92,597,834 字节的 v1.1.2 安装器并通过 SHA-256；未执行该安装器。该结果不代表原用户网络或所有运营商均已验证。

- `smoke-test.txt`：正式安装后 **118/118 项冒烟检查通过**，包含新增更新回归及现有品牌、播放器等检查。
- `installer.txt`：默认及取消桌面快捷方式、当前版本图标路径、覆盖升级保留测试资料、程序文件恢复、安装后运行及卸载清空测试程序与数据全部通过；未修改日常安装。

不因本轮冒烟通过宣称既有间歇问题根因已修复。v1.1.2 曾有窗口内全屏尺寸 1280×719 / 1280×779 不一致；虎牙抽查线路 HTTP 403、底栏隐藏及预取的历史间歇失败记录继续保留。本次未重复四平台全线路、150%/200% 实机、高对比度系统切换或长期性能测量。
