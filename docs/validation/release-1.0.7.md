## 已复现问题与回归

- 分类容器回收时清空 URL 会覆盖绑定，导致返回后名称仍在、图片不再恢复；现在保留 URL 绑定，卸载仍释放像素。真实缓存页面与滚动回收场景均验证了图片重新绘制。
- 顶栏原生点击区域曾在侧栏收放后使用旧坐标，见 [失败记录](v1.0.7/native-regions-red.txt)。采用当前页原生 TitleBar 的布局区域更新，离页关闭监听；正式构建已检查平台和刷新按钮的实际原生区域。
- 1192 宽度下卡片首行仅占到 1013，留下整列空白，见 [失败记录](v1.0.7/grid-red.txt)。按物理像素向下取整后，通过浅深色和多种宽度检查。
- 七列完整铺满后，原 80 条测试数据不再保证触发回收，曾中止检查，见 [原记录](v1.0.7/image-fixture-incomplete.txt)。夹具增至 240 条，明确确认实际回收后才验证返回图片，最终 7 项通过。

## 验证边界

- 本机实际缩放为 100%；150%/200% 实机、高对比度实际切换、多显示器与四平台全部真实线路未完整验收。
- 没有重复长期性能对照，不承诺 CPU 或内存全面下降，也不把可控图片、数据和媒体检查等同于所有真实直播均已验证。
- v1.0.5 的 B站访客首页与虎牙所选播放线路未通过记录继续保留，未宣称本轮已修复。
- 旧版覆盖升级通过本轮同一隔离安装身份的重装场景验证；未在日常安装上执行真实跨版本升级。日常卸载仍会清空全部 PlayWin 用户资料。
