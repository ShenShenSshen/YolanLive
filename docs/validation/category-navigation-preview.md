# 分类两层导航本地预览

2026-11-03，基于 1.1.5。只调整分类页的平台导航、游戏大类和搜索排布；不改平台接口、分类 ID、浏览记忆、游戏图片来源或播放逻辑。未生成安装包、未发布 GitHub。

## 布局

- 保留更纱 UI SC Regular、14 逻辑字号和 20 行高。沿用灰白背景 `#F7F8FA`、正文 `#252C36`、蓝紫强调 `#5967B7`、淡选中底 `#EAEDFA` 及现有深色／高对比主题资源。
- 分类页四个平台保持原顺序，使用等宽 88×44 的原生列表项与现有下划线。去掉这层的额外外边距，平台、大类与卡片左边缘共用内容起点。现有 72 高顶栏保留顶部呼吸空间及窗口按钮避让。
- 大类不再固定 112 宽，使用文字宽度、左右各 14 内边距、最小高度 36 和 8 间距；空间不足换行，长标签可完整换行显示。保留原生单选、自动化选择、键盘焦点和淡色 8 圆角选中块。
- 大类导航使用一个仅供少量导航项使用的本地换行面板；游戏卡片继续采用已有虚拟化网格。没有新增 NuGet 包、轮询器或常驻动画。
- 分类页全平台搜索固定为顶部图标入口，点击后沿用现有输入弹层；当前平台的找游戏输入框留在大类右侧，提示明确标出平台。
- 内容宽度不足 640 时，找游戏输入框收为按钮，不额外占一行。弹层复用同一个输入框及绑定；保留筛选词，按钮以小标记和悬停全文说明当前筛选。离开页面关闭弹层并退订文本属性回调。
- 两层导航保留 12 间距，大类到卡片保留 16。使用约 100ms 原生状态过渡及原有 160ms 选择反馈，文字不缩放，数据加载不等待动画。

## 验证与边界

使用本机工具、D 盘缓存与隔离访客目录。可运行目录为 `artifacts/YolanLive-category-nav-preview/`，exe 版本仍为 1.1.5.0。

- 浏览检查 8 项通过：本地搜索范围与清除、紧凑搜索弹出／输入／焦点／返回、筛选标记、按名称宽度布局、换行、自动化单选、浅深主题反馈、固定与取消固定、图片和缓存页面返回。
- 原生布局检查 25 项通过：四个平台完整显示、浅深主题、内容宽度 280／480／640／960／1280、960×540 与 1280×720 窗口、侧栏展开和收起、刷新与窗口按钮的避让、原生拖动区域不拦截按钮，以及共享字体、游戏卡片、关注、历史和设置的现有检查。分类页新增全平台搜索弹层的圆角、间距和键盘输入断言。
- 检查曾捕获筛选文本已生效而标记未同步的问题：改为跟随 Text 依赖属性变化并在页面离开时退订后，原失败用例通过。没有放宽标记、绑定或缓存返回断言。
- 实际 RasterizationScale 为 1；150%／200% 实机、高对比系统切换、关闭动画后的实际手感仍需人工体验。未重复平台网络或完整播放器测试，不宣称处理了既有全屏视口失败。

原始通过记录和失败记录保留在忽略提交的 `artifacts/category-navigation-checks/`。本轮不改已发布的 1.1.5 软件包及校验文件。
