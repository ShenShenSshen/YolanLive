# 游岚 YolanLive v1.1.1 发布检查

日期：2026-10-22。以 v1.0.10 为基线，发布当前已确认的雾蓝布局、导航搜索、卡片反馈及刷新重试调整。版本统一为 1.1.1；沿用安装 AppId、用户数据目录和旧版直接升级机制。

版本号按用户确定的“满 10 进 1”规则延续；历史 v1.0.10（新规则对应 v1.1.0）不重写标签或发布资产。本次未发布过 v1.0.11。

## 变更与检查范围

- 界面演进与本地预览记录见 [设计说明](../design/option1/preview.md)。播放器只保留此前已确认的按钮视觉与空间预算调整，本轮不为修复测试而修改播放或窗口逻辑。
- 使用本机工具及 `with-build-cache.ps1` 将 NuGet、构建和隔离访客检查缓存保留在 D 盘；检查不读取日常账号。
- 预览检查：115 项冒烟中 114 项通过，25 项界面通过。新增受控检查覆盖刷新保留、失败重试、重复点击、取消后过期结果抑制、300 条上限及成功空列表。浅色／深色窄页检查覆盖错误文字对比度与键盘重试。
- 预览曾未通过 `Player pause, volume, double-click and idle controls`：窗口内全屏视频区域期望 1280×719、实际 1280×779，缩放 100%。[失败原始记录](v1.1.1/preview-smoke-failure.txt)保留；正式安装构建本次 115 项通过，但未确认该间歇性问题的根因已消除。

## 范围与限制

不重复四平台全线路实际播放、长期性能、150%／200% 实机字体及系统高对比度切换。既有 B站访客选房失败与虎牙所选线路失败记录继续保留。没有将隔离夹具检查等同于平台实际播放验证。

Satoshi 字体随应用嵌入，许可随包；字体原文件不作为源码镜像跟踪，源码构建获取方式见设计说明。Windows 图标缓存的全部机器环境仍需人工体验。

覆盖升级保留设置、关注、历史与登录；安装版卸载清空应用数据。安装器和程序仍未签名。
