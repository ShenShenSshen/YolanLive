# YolanLive v1.1.5 发布检查

2026-11-02。发布已确认的“圆体大标题＋更纱 UI SC”搭配及 D4 蓝青双色风翼图标。软件、关于页版本来源和安装器统一为 1.1.5；平台接口、播放参数、窗口模式、页面布局和用户数据格式不变。

## 字体与图标

- 页面大标题与字标使用资源圆体 Regular；正文、导航、按钮、说明、数字及直播间标题栏使用更纱黑体 UI SC Regular。共享资源统一，字号与行高保持原值，不缩放整个控件。
- 更纱来自官方 v1.0.43 带微调 TTF，原字体与 OFL 1.1 授权随软件提供，无需安装系统字体。`font.json` 记录文件大小、SHA-256 和 `cvt `、`fpgm`、`prep` 表验证。旧字体资源保留用于原生对照。
- SVG、PNG 和 ICO 同步为 D4 风翼：底色 `#EFF8FC`，上翼 `#5F91C9`，下翼 `#60B8BC`；ICO 包含 16、20、24、32、40、48、64、96、128、256 像素资源。
- README 介绍图标改用 `docs/branding/yolanlive-d4.png`，文件与程序 PNG 相同，使用新路径减少旧图缓存影响；同步下载链接、字体说明和授权介绍。
- 安装器沿用 AppId、当前用户安装、版本化快捷方式图标与 Shell 刷新通知；覆盖升级保留资料，卸载清空资料。

原尺寸对照和本地整合记录见 [字体对照](font-preview.md)、[实际界面整合](visual-adoption.md)。

## 正式构建验证

全部构建使用本机工具和 D 盘缓存；运行检查使用隔离访客或测试安装身份，不读取日常账号，不覆盖日常安装。原始证据在 `v1.1.5/`。

- `versions.json`：exe、主程序集与安装器文件版本为 1.1.5.0，安装器产品版本为 1.1.5；程序与安装器均未签名。
- `visual.txt`：25 项原生布局及字体角色检查通过，覆盖浅深主题、窄窗口、导航、搜索、标题、图片与设置。大标题和 UI 字体、数字资源及授权文件均有明确断言，未放宽字号、行高、字重、对比度或裁切检查。
- `icons.txt`：正式 exe 与安装器内嵌 D4 图标均与源 ICO 逐像素匹配。
- `update-offline.txt`：9 组现有更新回归通过，覆盖版本和安装包识别、大小与 SHA-256、断点续传、损坏拒绝、取消、超时、后台下载和手动启动安装器。
- `package.json`：便携 ZIP 共 586 个文件，逐文件 SHA-256 与正式运行目录匹配；依赖、更纱和资源圆体及对应许可齐全，无账号、数据库、日志或测试目录。
- `legacy-offline.txt`：不可变 v1.0.6 更新器接受直接升级至 v1.1.5 的兼容元数据，仍拒绝跨仓库安装包，旧更新入口需要同步。

- `installer.txt`：取消桌面快捷方式、当前用户安装、版本与默认 D4 图标、旧图标路径替换、覆盖安装恢复程序文件和保留测试资料通过。
- `smoke-test.txt`：安装后 **117/118** 项通过，唯一失败仍为 `Player pause, volume, double-click and idle controls` 中的既有视口尺寸断言，预期 1280×719、实际 1280×779、缩放 1，与预览和上一版正式构建记录一致。完整错误栈保留，安装检查脚本因该失败整体退出 1；未修改断言或重跑以替代失败。
- `installer-cleanup.txt`：finally 卸载后独立核对，测试注册表、桌面与开始菜单快捷方式、程序文件及假用户资料全部移除，日常安装未受影响。

## 限制与发布核对

本轮未重新测量长期性能、四平台所有真实线路、登录后播放、150%/200% 实机缩放或系统高对比度切换。原有窗口内全屏视口预期 1280×719、实际 1280×779 的间歇失败，虎牙抽查线路 HTTP 403，以及软件内无显式代理完整更新下载超时记录保留，不宣称这些根因已修复。实际字体清晰度受显示器、缩放及系统渲染影响。
