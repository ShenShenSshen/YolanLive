# YolanLive v1.1.2 发布检查

2026-10-28。基于 v1.1.1 发布已确认的浅色影音界面与未发布的播放稳定性修复。程序和安装器统一为 1.1.2，保留安装身份、用户资料格式及旧版直升入口。

设计与预览验证见 [界面说明](../design/light-media/preview.md)，播放修复与红绿记录见 [稳定性说明](stability-round1.md)。不改变播放参数、视频比例或窗口模式规则。概念稿中的示意素材不打入程序，实际继续使用平台原图。

预览界面 25 项通过；完整回归 115/116，旧窗口内全屏尺寸断言曾失败：期望 1280×719、实际 1280×779。保留失败，不因发布或单轮通过宣称根因消除。虎牙访客抽查三条线路 HTTP 403、底栏隐藏及预取的历史间歇失败也保留。未重新验证四平台全线路、登录后播放、150%／200% 实机和长期性能。

正式构建使用 D 盘缓存与隔离访客数据，不读取日常账号。原始结果见本目录 `v1.1.2/`：

- `versions.json`：程序、程序集与安装器统一为 1.1.2。
- `visual-checks.txt`：正式构建 25 项界面检查通过。
- `smoke-test.txt`：安装后 116 项中 115 项通过，失败为上述既有窗口尺寸断言，未隐藏或删除。
- `installer.txt`：默认／取消桌面入口、图标路径替换、覆盖安装保留资料通过；整体检查因安装后冒烟失败而未全部通过。随后确认隔离卸载清空测试注册项、程序与数据。最终包仅同步 README 说明后重建，应用二进制不变。

- `package.json`：便携包全部文件逐一 SHA-256 核对，必需依赖、字体许可齐全，不含账号、设置、数据库、日志或测试目录。
