# YolanLive v1.1.4 发布检查

2026-11-02。基于 v1.1.3 汇总此前通过的关注分组、整体可用性及六项浏览体验调整，程序、关于页版本来源和安装器统一为 1.1.4。保留当前字体、配色、磨砂和四平台接口，没有新增依赖。

## 发布内容

- 关注同时展示直播中、未开播、状态待确认，查询失败不当作停播；分组数量、标签对比度及未知平台记录保留。
- 关注和历史本地筛选；关注刷新差量更新并恢复可见锚点与键盘焦点，历史按日期组织。
- 浏览窗口允许原生缩放和最大化，离开播放恢复浏览状态。窗口记忆仅增加可选字段，兼容旧设置；SQLite 和关注／历史导入导出格式不变。
- 顶栏全平台搜索在窄窗口保留原位置，提供原生输入浮层；统一窗口、登录与管理名称，删去多余说明。
- 直播封面按约 280 DIP 目标宽度分列；分类“找游戏”本地跨当前平台大类筛选；固定操作可悬停或用键盘发现，已固定状态常显，沿用原右键菜单及每平台 6 项上限。
- 游戏原图完整显示，统一安全留白、浅深主题背板及缺图文字对比度；缓存页面返回不重复整页淡入。
- 播放提示对应实际请求、连接与缓冲阶段，取消后清除请求提示；不改变解码、播放缓冲、窗口模式、重试或随机选房规则，不宣称实际首帧更快。
- 更新失败后可重试、打开浏览器或复制链接，元数据不可用时仅提供本项目发布页；仍需校验大小及 SHA-256，并由用户手动启动安装器。

前轮设计与失败定位记录分别见 [关注分组](favorite-groups.md)、[整体可用性](usability.md)、[浏览体验](browsing-polish.md)。这些预览报告记录当时 1.1.3 的本地状态；本次正式发布构建的证据集中在 `v1.1.4/`。

## 正式构建验证

使用本机 .NET、Windows SDK 和 Inno Setup，全部大文件缓存与访客检查目录位于 D 盘，不读取日常账号，不覆盖日常安装。

- `versions.json`：exe 和主程序集文件版本为 1.1.4.0，安装器产品版本为 1.1.4。关于页从实际程序集读取版本。程序与安装器均未签名。
- `browsing.txt`：7 项新增浏览体验检查通过，覆盖封面尺寸与比例、跨大类本地过滤、清空与返回恢复、固定／取消／键盘操作、图片留白、返回动画及加载取消。
- `usability.txt`：7 组整体可用性检查通过，含原有关注分组、本地筛选、差量刷新、历史日期、浏览／播放窗口恢复、窄窗口全局搜索、可见位置与焦点及更新失败操作。
- `visual.txt`：25 项原生布局检查通过，覆盖浅深主题、侧栏、窗口按钮与搜索交互区、完整标签、图片比例、缺图文字对比度、设置及失败重试。
- `images.txt`：7 项图片回归通过，包含实际 HTTP 解码与渲染像素、页面返回、缓存导航、容器回收、取消补图重试及失败来源回退。
- `update-offline.txt`：9 组现有更新检查通过，覆盖 Range 续传、损坏文件拒绝、底层取消、真实连接及读取超时、跨页面下载和手动安装。
- `icons.txt`：正式 exe 与安装器均嵌入当前 D1 风帆图标；安装器继续使用带版本号的快捷方式图标路径。
- `package.json`：便携 ZIP 共 584 个文件，全部逐文件 SHA-256 与正式运行目录匹配，必需运行依赖与字体许可齐全；没有账号、数据库、日志或测试目录。
- `legacy-offline.txt`：不可变 v1.0.6 更新器接受直接升级至 v1.1.4 的元数据，并继续拒绝不同仓库地址，旧更新兼容入口仍需同步。

- `installer.txt`：允许取消桌面快捷方式、当前用户安装、1.1.4 版本与默认快捷方式、旧图标路径替换、覆盖安装恢复程序文件及保留测试资料通过。安装后的冒烟为 **117/118**，因下述历史全屏尺寸问题，安装检查脚本整体退出 1；不宣称整套安装检查全绿。
- `smoke-test.txt`：失败项为 `Player pause, volume, double-click and idle controls`，窗口内全屏视频区域预期 **1280×719**、实际 **1280×779**、缩放 1，复现已有间歇问题，原断言与完整错误栈保留。前一轮本地 1.1.3 预览的 118 项通过结果仍作为历史证据保留，未用重跑成功替换本次失败。
- `installer-cleanup.txt`：脚本 finally 完成卸载后独立核查，测试注册表、开始菜单与桌面快捷方式、程序文件、假用户资料全部移除，日常安装与资料未受影响。

## 限制及发布核对

本轮未重复四平台真实全线路、登录后播放、长期性能、150%/200% 实机缩放或系统高对比度切换。历史窗口内全屏 1280×719 / 1280×779 间歇失败、虎牙部分抽查线路 HTTP 403、v1.1.3 发布后软件内无显式代理完整下载超时继续保留，未宣称根因修复。公共下载源的可用性不受项目控制，检测更新仍依赖 GitHub API。
