# 雾蓝静序：第 1 张设计的 WinUI 3 预览

设计参考为同目录的 `selected-reference.png`，对应用户选择的第一张效果图。原版雾蓝微调预览保留在 `artifacts/YolanLive-mist-preview`，本次使用独立目录 `artifacts/YolanLive-option1-preview`，版本仍为 1.0.10。

## 本次实现

- 宽窗口默认展开 188 DIP 侧栏，保留原生折叠、系统导航动画、选中提示、键盘焦点和顶部导航设置。
- 首页和分类页顶部左侧为平台切换，右侧为圆角搜索与刷新；搜索继续使用原有平台链接解析和统一搜索。
- 顶栏高 72，平台外框圆角 12、内项圆角 8，搜索高 38、圆角 19。原生标题栏内部高度同步调整，避免只增加外部高度导致内容裁切。
- 窄窗口将平台选择移至下方；空间进一步不足时恢复侧栏搜索，保留输入内容。标题栏搜索、刷新、平台按钮继续排除在窗口拖动区域外。
- 页面背景为 #F2F5F9。直播卡片保持 16:9 封面、10 DIP 圆角、透明信息区、标题省略与全文提示；不增加首页宣传横幅或自动播放预览。
- 圆体导航与微软雅黑 UI 正文保持原生字号；独立观看数字使用 Fontshare Satoshi 常规字体，中文单位回退到微软雅黑 UI。
- 直播卡片悬停增加 120ms 遮罩及播放提示；图片加载完成后约 160ms 淡入；普通页面的 160ms 入场只作用于内容，顶栏与搜索保持稳定。
- 平台和游戏大类沿用 160ms 选中淡化反馈，侧栏、按钮及原生菜单使用系统反馈；本版没有另加跨行滑动选中底板或自定义菜单弹簧效果。
- 动画遵循 Windows 动画开关，不增加循环动画、轮询或第二个播放器。离开页面和卡片回收时清理反馈状态。
- 播放器的既有底栏分组、向下外展、原生拖动、视频尺寸及播放参数不变。

## 字体来源

Satoshi 从 Fontshare 官方下载包取得，常规字体文件未修改，原许可随预览放在 `Assets/Fonts/Satoshi-LICENSE.txt`。许可允许应用内使用与嵌入；字体原文件排除在 Git 跟踪之外，避免将源码仓库作为字体镜像。源码重新构建时需从 https://api.fontshare.com/v2/fonts/download/satoshi 取得字体，将 `Fonts/WEB/fonts/Satoshi-Regular.ttf` 放入项目 `Assets/Fonts`。应用不在运行时联网加载字体。

## 检查范围与体验

使用 D 盘缓存与隔离访客目录编译及检查，不读取日常账号。界面夹具检查包含浅色／深色、展开／收起侧栏、窄内容区、分类与卡片图片比例、搜索圆角、标题栏交互区域、设置换行。夹具图片用于测量布局，不代表真实直播内容；软件仍从原有平台接口读取直播与分类。

当前实屏缩放为 100%；150%、200% 的字体渲染、系统高对比度及实际鼠标动画手感保留人工体验。软件界面是可运行的原生实现，生成设计图中的具体直播封面与文字不作为内置数据。
