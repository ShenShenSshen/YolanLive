## 视觉与布局

- 主背景 #F7F8FA、正文 #252C36、说明 #627083、强调 #5967B7、选中浅底 #EAEDFA；播放器使用同一组灰白、石墨和蓝紫资源。深色提供相应色板，高对比度保留系统颜色。
- 字体沿用资源圆体导航、微软雅黑 UI 正文与原数字字体。正文 14、说明 13，保持原生字号及系统缩放，没有缩放整页或增加字体依赖。
- 展开侧栏由 188 调为 176 DIP，保留原生折叠、图标、键盘焦点、设置入口和选中提示。顶部平台、圆角搜索及刷新继续复用已验证的标题栏空间预算，避免窄窗口与系统按钮重叠。
- 平台入口改为透明底与 2 DIP 下划线；大类仍为淡色轻标签，明确区分两层导航。下划线位于内容模板，跟随原生 ListView 选择状态更新；不改导航数据，不增加轮询或独立动画状态机。
- 首页直播目标宽度由 280 调为 320 DIP，按实际内容区均匀分列，常用窗口得到较大的封面；继续保持 16:9、单行标题、全文提示和次级主播信息。
- 去掉常看游戏上方重复标题，保留快捷入口及其读屏名称。分类沿用透明底、4:3 图片区域、等比完整显示、两行名称和原生悬停反馈。
- 播放器沿用播放／声音亮度／画质线路／窗口操作分组，仅更新共享颜色；既有高度、组间距、等宽伸缩、小窗收纳、向下外展、拖动及全屏规则不变。
- 关注、历史与设置共享新色板，保持既有功能与信息层级。

## 检查

使用 D 盘缓存构建，检查使用隔离访客目录。沿用原生布局检查，并补充实际平台项切换后的下划线可见性与对比度；透明选中背景按实际页面背景核对，4.5:1 阈值不变。

首次包装原生列表容器的模板触发运行异常，已回到原生容器，以内容模板绘制下划线；该失败记录保留在 `artifacts/light-media-checks`。未更改播放逻辑以通过界面检查。

最终本地构建成功，版本 1.1.1。界面检查 25 项全部通过，覆盖浅色／深色、侧栏展开／收起、960×540 顶栏、280／480／640／960／1280 内容宽度、原生键盘选择、下划线与完整标签。

完整回归 116 项中 115 项通过；失败仍为既有 `Player pause, volume, double-click and idle controls` 的窗口内全屏尺寸断言：100% 缩放期望 1280×719、实际 1280×779。原断言与失败记录保留，没有改动窗口或播放业务逻辑以通过检查。此预览不宣称全部回归通过。

原始日志为 `artifacts/light-media-checks/visual-checks.log` 和 `smoke-test.log`。实际 150%／200% 字体渲染及高对比度切换未进行实机验收；没有重复四平台实际取流或长期性能测量。既有虎牙 HTTP 403、底栏隐藏及预取间歇性问题仍以此前记录为准，不因视觉调整宣称修复。

## 源码入口

- `YolanLive.WinUI/ValueDictionary.xaml`：共享色板、平台样式、直播卡片目标宽度。
- `YolanLive.WinUI/Helper/PlatformTabAnimation.cs`：一次性选中指示同步及已有淡化反馈；无后台轮询。
- `YolanLive.WinUI/MainPage.xaml`：侧栏布局。
- `YolanLive.WinUI/Views/RecomendPage.xaml`、`CategoryPage.xaml`：平台项与快捷入口布局。
- `YolanLive.WinUI/VisualDesignChecks.cs`：原生选择、布局及文字检查。
