# 合并顶栏本地预览

本记录保留发布前的本地预览过程；正式交付归入 [v1.0.7 发布检查](validation/release-1.0.7.md)。

日期：2026-10-19。基于 1.0.6，保持版本号；未生成安装器，未上传 GitHub。

## 本次调整

- 默认左侧导航模式下，移除单独的空白标题行。平台切换、刷新和原生窗口按钮位于同一行，侧栏从顶部贯通；空白部分用于系统原生拖动。
- 首页、分类、关注、历史、设置采用共享的 WinUI TitleBar；搜索与分类详情保留原生返回按钮。
- 平台切换外框高度由 44 收薄为 36，内部选中块为 28；保持 48 高的顶栏及 14 号文字，顶边自然留出 6，文字、刷新和窗口按钮保持垂直居中。
- 游戏大类位于第二行，与平台导航及卡片共用左边缘；保留当前雾蓝、磨砂和字体。
- 空间不足时，平台切换移至独立一行并允许换行，完整展示四个平台名称。
- 设置页标题与最大宽度 1040 的居中面板对齐；移除侧栏内容区多余的上边框与转角。
- 修正自适应卡片宽度的物理像素取整，避免最后一张卡片换行、右侧空出整列。
- 保留本地分类图片返回修复，回收容器时不再覆盖图片 URL 绑定。
- 原生顶栏仅在当前浏览页启用交互区域更新；离页后关闭布局监听。未增加轮询计时器，直播间现有底栏、全屏、小窗规则保持不变。

## 验证

- 卡片空列用例先失败（1192 宽度中首行仅占至 1013），修复后通过。
- 最终构建：19 项界面检查通过，覆盖浅/深色、280–1280 逻辑宽度、侧栏收放、原生交互区域、设置面板及离页停止监听。
- 最终构建：7 项图片检查通过，覆盖同名补图、实际 HTTP 解码与像素、页面返回、容器回收和取消恢复。原 80 条数据在七列布局下未触发回收，夹具增至 240 条后确认实际回收，再完成验证。
- 卡片修复后的完整回归：113 项通过，涵盖播放器及窗口模式；最终增加的离页监听关闭规则另由上述界面检查覆盖。
- 编译、测试及临时文件使用 D 盘缓存和隔离访客目录，未读取日常登录资料。
- 本机实际缩放为 100%；150%、200% 实机显示与系统高对比度仍待人工体验，未声称完成全部显示器验证。
