# 云白·松青 A 版：本地预览

以 YolanLive v1.0.10 为基线，版本号保持 1.0.10。本轮不生成安装包、不发布 GitHub，也不覆盖正式发布目录。

## 视觉调整

- 浅色：背景 `#F3F6F5`、白色面板、正文 `#243A36`、说明 `#60736E`、松青强调 `#276D63`、选中浅底 `#DDEDE7`。深色提供对应的低饱和青绿色；高对比度继续使用系统颜色。
- 正文及控件保持微软雅黑 UI 常规字重 14，说明 13；标题与导航沿用资源圆体，不增加字体依赖，不缩放文字。
- 首页与分类的顶栏整合平台切换、搜索和刷新，保留原生窗口按钮和拖动区；空间不足时平台换行、搜索回到侧栏。搜索继续共用原有链接解析和导航。
- 侧栏宽窗首次展开，宽度 184，保留手动收起及顶部导航设置。常看游戏改为标签与快捷入口同行，入口继续换行，空列表隐藏。
- 直播卡片保留 16:9 无底板展示；游戏卡片采用 12 圆角面板、8 圆角图片框和上图下名，图片保持 4:3 完整显示。关注、历史和设置同步使用共享色板与圆角。
- 播放器仅更新颜色及控件圆角；保留底栏高度、等宽画质/线路、小窗精简、向下外展、原生拖动、播放参数和资源策略。
- 沿用平台选中与页面的 160 毫秒反馈及系统控件交互，遵循系统动画设置，不新增轮询或循环动画。
