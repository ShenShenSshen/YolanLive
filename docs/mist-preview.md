# 雾蓝微调预览

本轮按用户确认恢复 v1.0.10 的雾蓝配色和布局。A 版试稿不再作为当前设计方向，保留在本地备份中供参考。

- 保留原版侧栏搜索、默认收起导航、平台切换和卡片布局。
- 搜索框高 36、圆角 18，使用原生输入模板，文字明确左对齐。
- 普通播放器的播放组与音量／亮度组之间保持 24 的间距，其余空余宽度分配给中间区域。
- 刷新与更多按钮统一为 40×40，同时调整空间预算，保留窄窗口精简栏和等宽画质／线路。
- 保留当前字体、磨砂、播放逻辑、用户数据与窗口模式。

版本保持 1.0.10，仅生成本地预览目录 `artifacts/YolanLive-mist-preview`，本轮不生成安装包、不发布 GitHub。

运行前先退出其他预览实例，再打开目录内的 `YolanLive.exe`，避免单实例机制转到旧预览窗口。

验证：隔离目录内的现有冒烟检查 113 项通过，界面检查 19 项通过。日志位于 `artifacts/mist-preview-checks`，保留先前失败日志用于对照。播放器检查在布局稳定后停止悬停计时并收起工具栏，避免鼠标位置使测量期间的外展栏重新出现；视频尺寸断言继续保留。当前实际缩放为 100%；150%、200% 的实屏字体效果与系统高对比度仍需人工查看。
