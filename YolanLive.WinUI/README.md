# YolanLive（游岚）v1.1.6

Windows x64 游戏直播客户端，基于 WinUI 3。项目主页：https://github.com/ShenShenSshen/YolanLive
原项目：https://github.com/xiaoyaocz/AllLive ，保留 MIT 许可证。

## 运行与安装

安装版支持当前用户安装、覆盖升级和卸载，默认创建桌面快捷方式；便携版解压后运行 YolanLive.exe，必须保留整个目录。程序自带 .NET 和 Windows App SDK 运行依赖。抖音、虎牙、斗鱼网页登录及部分平台请求需要 WebView2 Runtime。

支持 Windows 10 1903 及以上版本、Windows 11 x64。程序和安装包尚未进行代码签名。

覆盖升级保留 YolanLive 数据；卸载安装版会清空登录、关注、历史、设置、日志、更新下载及专用浏览器缓存，全部不保留。普通数据目录沿用 %LOCALAPPDATA%\PlayWin（兼容旧版）；发布包不包含个人账号数据。

## 平台与浏览

支持哔哩哔哩、抖音、虎牙、斗鱼，首页和分类仅展示游戏。四平台独立记住大类与常看游戏，每个平台最多固定 6 项。游戏分类采用上图下名，抖音缺图时尝试使用其他平台同名游戏封面，仅补图，不改变分区或跳转；没有匹配时保留占位。

搜索、关注、历史统一管理，搜索显示平台标识。首页与分类隐藏已确认停播房间；关注按直播中、未开播、状态待确认分组，历史按今天、昨天、更早分组，均支持本地筛选，支持 JSON 导入导出。分类“找游戏”筛选当前平台已加载目录，卡片固定按钮支持悬停、键盘操作与取消固定。

分类页平台使用细下划线，游戏大类按文字宽度排列并自动换行；顶部保留全平台搜索按钮，大类右侧提供当前平台找游戏。窄窗口收起找游戏输入框，保留筛选词与状态标记，点击按钮继续输入。

侧栏“随便逛逛”从四平台随机挑选游戏直播，本轮支持上一个／下一个，到记录末尾继续随机；随机记录只保存在内存。

四平台各自登录、注销，网页会话与浏览器资料隔离，保存会话使用 Windows 当前用户保护。网络失败不等同于登录失效，不删除保存的会话。后台网页静音并禁止媒体播放。不提供弹幕、礼物、平台关注同步或跨设备同步。

## 播放与窗口

底栏按播放、音量与亮度、画质与线路、窗口操作分组；画质与线路等宽伸缩。宽窗口提供“窗口大小”“窗口模式”入口，窄窗口及小窗将次要操作收进更多。等待提示按实际请求、连接及缓冲阶段显示。

亮度只调暗视频遮罩，100% 为原始画面，不调显示器亮度。视频区域不响应单击、滑动、滚轮和右键操作；普通窗口使用标题栏拖动，窗口内全屏和置顶小窗使用系统原生视频区域拖动。双击切换整屏全屏，小窗双击恢复；空格暂停或继续。

普通窗口底栏常驻。窗口内全屏按进入前实际视频区域大小和位置展开，不自动置顶；置顶小窗视频为 480×270。这两种模式无白边，悬停时工具栏在视频外向下展开，允许暂时超出屏幕，不压缩视频；整屏全屏沿用自动隐藏悬浮栏。拖动时收起操作栏，允许跨屏及部分移出屏幕。

设置与播放器“窗口大小”菜单提供 960×540、1280×720、1600×900、1920×1080，默认 1280×720，尺寸指实际播放区域像素。浏览窗口支持调整大小、最大化和返回恢复；播放时沿用固定比例及预设，退出特殊模式恢复所选尺寸。视频始终保持原比例，允许黑边。

断流最多重试 3 次，间隔 2、5、10 秒；重新确认状态与播放地址，确认停播或登录失效时停止，离开房间取消。最终失败可手动重新播放。

## 性能与外观

复用 HTTP 连接，普通数据请求最多并发 4 个；页面离开、刷新、换平台或换房取消请求。游戏目录缓存 10 分钟，合并重复加载，手动刷新绕过缓存。最小化暂停列表状态检查；后台签名浏览器空闲 60 秒尝试暂停、5 分钟释放，需要时恢复或重建。

图片按显示尺寸及 DPI 解码，卸载时释放引用；未增加应用专用磁盘图片缓存。每页列表上限 300 条；设置变更合并保存，日志按既有规则滚动保留。没有设置线程数或进程内存硬上限，也没有改变正常解码和缓冲策略。

播放器复用鼠标指针；普通底栏常驻时停止无任务的隐藏计时，最小化暂停悬停检查，保留必要的断流恢复计时；窗口状态监听随卸载退订。已确认减少无效唤醒与重复对象创建，不代表 CPU、内存全面下降。

保留现有配色和磨砂材质，大标题使用资源圆体，导航、正文、按钮、说明及数字统一使用更纱黑体 UI SC Regular。沿用当前字号、行高及页面布局；应用图标为 D4 蓝青双色风翼。随包提供字体及 OFL 授权，不需要安装系统字体。页面过渡遵循系统动画设置，不增加轮询或循环动画。

## 更新

启动主窗口后台检测一次正式版，有新版本才提示；版本和校验信息直接取自 GitHub。设置后台下载安装包时依次尝试 gh-proxy.org、ghfast.top 和 GitHub 原站，失败自动换源，取消或网络中断后重试支持断点续传。连接 15 秒或连续 20 秒无数据时取消当前请求；整次下载最多 15 分钟。

只有大小与 SHA-256 校验通过才提供手动启动安装器，不自动安装。公共加速服务可能不可用；网络不支持续传时重新下载。旧版本需要先安装一次包含此次修改的版本，后续更新才能使用加速。

## v1.0.9：随便逛逛响应优化

补充修复：切换房间时，平台详情或画质调用即使未及时响应取消，也会按已有期限停止等待，恢复前后按钮；迟到结果不得重新发起播放。首间的“上一个”仍禁用，正在切换时仍暂时禁用两按钮以防重复请求。

已返回有效候选时不等待其他慢分区；按平台短时保留最多 24 个游戏房间，减少重复拉取首页。选房详情在同平台、同房间且 15 秒内交给播放器复用。随机播放后最多预取下一间的候选与详情，不预取画质或播放地址、不下载视频，离开后取消；普通打开、全屏及小窗规则保持不变。

首次冷启动、平台请求与视频缓冲仍可能慢。预览四平台访客检查中，抖音和斗鱼启动播放，B站访客选房与虎牙首条所选线路失败；未宣称四平台全面通过。完整原始记录见仓库 docs/performance/random-browse/REPORT.md。提供安装包、便携包与校验文件，版本统一为 1.0.9。
